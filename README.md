# Herald

Statyczna wersja demonstracyjna aplikacji Herald.

**Otworz strone: https://mknieszner.github.io/herald/#/**

GitHub Pages publikuje katalog glowny galezi `gh-pages`.
Repozytorium zawiera gotowe pliki dystrybucji; serwer aplikacji nie jest
potrzebny do otwarcia strony i korzystania z trybu demonstracyjnego.
Logowanie oraz integracje z zewnetrznymi uslugami wymagaja odpowiedniego API.
